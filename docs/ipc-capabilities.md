# Desktop IPC capabilities

The main process authorizes every invoke using the registered window role, exact trusted document, live WebContents, main frame and shutdown state. Each channel accepts exactly the documented number of arguments. Trusted hash routing does not change the registered role. Auxiliary windows do not gain authority by navigating to a main-window route. The sandboxed preload exposes purpose-built functions, not Electron events, a raw channel selector, filesystem writes, or a shell.

| Invoke channel                   | Roles      | Payload and validation                                                                                                                       | Result / side effect                                                                                                                                           |
| -------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open-main-window`               | Tray, Mini | None                                                                                                                                         | Opens or focuses main window.                                                                                                                                  |
| `quit-app`                       | Tray       | None                                                                                                                                         | Normal desktop shutdown.                                                                                                                                       |
| `copy-text`                      | Main       | String, ≤262,144 characters, no NUL                                                                                                          | Writes text to the system clipboard.                                                                                                                           |
| `set-tray-compact`               | Tray       | Boolean                                                                                                                                      | Commits only tray compactness, then resizes the popover; failed writes preserve the previous layout.                                                           |
| `show-mini-monitor`              | Main       | None                                                                                                                                         | Commits visibility preference and shows Mini; returns success.                                                                                                 |
| `hide-mini-monitor`              | Mini       | None                                                                                                                                         | Commits visibility preference and hides Mini; returns success. Hidden Mini is destroyed after a short grace period.                                            |
| `set-mini-monitor-always-on-top` | Mini       | Boolean; Mini must be visible                                                                                                                | Commits and applies pin state without creating a window; returns success.                                                                                      |
| `get-latest-metrics`             | All        | None                                                                                                                                         | Window/route projection, including legitimate initialization while paused. Rechecks authorization after waiting for the paused snapshot.                       |
| `get-network-connections`        | Main       | None                                                                                                                                         | Connection snapshot with status and timestamp; no mutation.                                                                                                    |
| `get-process-details`            | Main       | Integer PID >1, not Sentinel's main PID, within signed 32-bit range                                                                          | Details from a recent observation or null.                                                                                                                     |
| `reveal-process`                 | Main       | Valid PID, macOS, observed existing absolute path                                                                                            | Reveals the observed path in Finder. Does not accept a caller-supplied path.                                                                                   |
| `kill-process`                   | Main       | Exact PID/name/start token; valid snapshot identity and native checks; visible, nonminimized Processes view; one pending decision per sender | Cancel-default native confirmation, then identity/window revalidation before a signal; success, cancellation or error.                                         |
| `get-system-info`                | Main       | None                                                                                                                                         | Hardware and OS inventory.                                                                                                                                     |
| `get-thermal-metrics`            | Main       | None                                                                                                                                         | Thermal status, subject to platform and permissions. No elevated privileges are requested.                                                                     |
| `get-startup-metrics`            | Main       | None                                                                                                                                         | Read-only startup inventory; no startup-item write channel.                                                                                                    |
| `export-system-report`           | Main       | `json` or `txt`                                                                                                                              | Report payload for user-directed local export; no caller-supplied write path.                                                                                  |
| `export-diagnostic-bundle`       | Main       | None                                                                                                                                         | Redacted local diagnostic bundle payload.                                                                                                                      |
| `get-alert-history`              | Main       | None                                                                                                                                         | Alert entries.                                                                                                                                                 |
| `get-alert-analytics`            | Main       | None                                                                                                                                         | Alert aggregates.                                                                                                                                              |
| `get-tray-alert-summary`         | Tray       | None                                                                                                                                         | Unread count and latest title, not full entries or analytics.                                                                                                  |
| `get-alert-markers`              | Main       | One of the five supported History ranges, in minutes                                                                                         | Markers for the requested interval.                                                                                                                            |
| `mark-all-alerts-read`           | Main       | None                                                                                                                                         | Marks alerts read and publishes permitted projections.                                                                                                         |
| `clear-alert-history`            | Main       | None                                                                                                                                         | Clears alert history and publishes permitted projections.                                                                                                      |
| `get-settings`                   | Main       | None                                                                                                                                         | Stored preferences, actual OS login status (or unknown) and recovery status.                                                                                   |
| `get-ui-settings`                | All        | None                                                                                                                                         | Revision and role-projected preferences. Mini and tray get theme, style, pause and their own presentation; no saved profiles, main layout, or position.        |
| `save-settings`                  | Main       | Complete known settings schema and explicit boolean login intent flag                                                                        | Persists general settings, leaving UI settings intact. Applies explicit login intent only after persistence. Returns saved and actual login status separately. |
| `save-ui-settings`               | Main, Tray | Exact known patch schema; Main cannot write internal Mini keys; Tray may only write the pause key                                            | Atomic preference commit. Unknown, malformed or mixed forbidden keys have no side effects.                                                                     |
| `import-appearance-profile`      | Main       | None                                                                                                                                         | Visible main window opens a native picker; only bounded, validated profile data is returned for review.                                                        |
| `export-appearance-profile`      | Main       | Exact version-1 profile schema                                                                                                               | Visible main window opens a native picker; creates a new JSON file only. Renderer cannot supply a path.                                                        |
| `get-history-downsampled`        | Main       | One of the five supported History ranges, in minutes                                                                                         | Only populated minute buckets; no record creation.                                                                                                             |

| `ui-settings-changed`        | Main, Tray, Mini                                                        | Revisioned committed snapshot projected by role.                                                                                                            |

| `tray-alert-summary-updated` | Tray                                                                    | Count and title only.                                                                                                                                       |

Exact origin/document checks also gate outbound messages. Window navigation and redirects are denied outside the app document; an unexpected committed main document loses its role and the window is destroyed. The production process kill path still has a residual operating-system PID reuse race; see [desktop reliability](desktop-reliability.md).

`get-process-page` accepts one validated request from the visible, non-minimized main Processes route. It searches the latest valid bounded inventory and returns no more than 50 summary rows. It cannot run commands, refresh the hardware probe, return private command arguments, or bypass paused display, detail, or termination authorization.

Storage channels are available only to the trusted main frame on the visible, non-minimized Storage Explorer route:

| Channels                                          | Arguments and authority                                                                                                                                                                                     |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `storage-session`, `storage-choose`               | None. Reads the caller's current scan status or opens a single-folder native picker. The renderer cannot submit a scope path.                                                                               |
| `storage-start`, `storage-cancel`, `storage-drop` | One opaque scan ID owned by the same WebContents. Starts or replaces the selected scan, requests cancellation, or disposes results. A restart issues another ID.                                            |
| `storage-query`                                   | A scan ID and exact bounded query. Directory/item IDs resolve only against that index. Returns at most 50 rows and 20 map nodes. The selected result's display path never authorizes any filesystem action. |

Storage inventory is never sent to tray/Mini Monitor or included in diagnostic exports.

Duplicate analysis has separate authority. These channels require the trusted main frame on the
visible, non-minimized Duplicate Files route:

| Channels                                                | Arguments and authority                                                                                         |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `duplicate-session`                                     | None. Returns platform capability and the caller's current session metadata.                                    |
| `duplicate-choose`                                      | Exactly `exact` or `photos`. Single-folder native authorization; no caller-supplied paths and no content reads. |
| `duplicate-start`, `duplicate-cancel`, `duplicate-drop` | Caller-owned session UUID. Reauthorize and start (new UUID), request cancellation, or discard session data.     |
| `duplicate-query`                                       | Session UUID and strictly bounded filter, sort, selection, and pagination. At most 30 groups and 30 members.    |
| `duplicate-preview`                                     | Session UUID, group ID, and an indexed member ID in that group. Returns at most two sanitized PNG thumbnails.   |

Neither Analyzer authorizes the other. Only one of the two scans may run at once. The image
decoder has no preload, role, application IPC, or access to file paths. Its separate ephemeral
Chromium session denies external requests and permissions. No inventory, hashes or previews
are persisted or added to monitoring broadcasts or diagnostics.
